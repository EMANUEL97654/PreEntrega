# Nebula Books

Nebula Books es una tienda ficticia de libros de ciencia ficción desarrollada como proyecto de práctica de HTML y CSS.

## Características

- Catálogo de productos.
- Diseño responsive.
- Sección de reseñas.
- Formulario de contacto.
- Contenido multimedia.
- Tabla de contactos ficticios.
- Enlaces a redes sociales.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts
- Font Awesome
- Formspree

## Formulario de contacto

El formulario de contacto utiliza Formspree para permitir el envío de mensajes sin necesidad de desarrollar un servidor propio.

El formulario se conecta con Formspree mediante el atributo `action` de la etiqueta `<form>` y utiliza el método `POST`.

Los datos enviados son:

- Nombre
- Correo electrónico
- Mensaje
